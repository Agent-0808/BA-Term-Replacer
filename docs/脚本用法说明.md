# 脚本用法说明

日常操作手册。工具原理见 [HOW_IT_WORKS.md](HOW_IT_WORKS.md)。所有命令在仓库根目录执行。

## batr 主命令（src/batr）

把繁中 ExcelDB.db 做字段级文本补丁，输出 CRC32 与输入一致的库（客户端 catalog 校验直接通过）。

```pwsh
# 繁→简（默认流程）：tw2sp + 默认词表
uv run batr work/db/ExcelDB.db --out output/ExcelDB.db --verify

# 繁→繁民译：不转字形，只用自制词表
uv run batr work/db/ExcelDB.db --convert none --names glossary/names_custom.tsv --text glossary/text_custom.tsv

# 预演：只统计会改什么、逐条打印词表命中数（hits），不写任何文件
uv run batr work/db/ExcelDB.db --dry-run
```

常用参数：

| 参数 | 作用 |
|---|---|
| `--convert {tw2sp,t2s,none}` | tw2sp 含台湾用词转换；t2s 只转字形；none 只做词表替换 |
| `--names` / `--text` | 显式指定词表（传入后默认表不再加载；terms.tsv 仍始终加载） |
| `--dry-run` | 预演，排查词条用（重点看 `hits=0` = 键拼错或过期） |
| `--verify` | 完成后对输出库跑 `PRAGMA integrity_check` |
| `--no-ascii-exact` | 关闭纯 ASCII 字段的 exact 匹配（默认开启，覆盖 "Kei" 这类拉丁角色名） |
| `--tables 正则` | 限定处理的表名，默认含 `Localize/Dialog/Scenario/.../Messanger/SNSProfile` |
| `--convert-kana` | 不跳过含假名字段（默认跳过：日文列是 GL 死数据） |

词表加载顺序（重复键先出现者优先）：`*.local.tsv` → 自动表 → `terms.tsv`。匹配顺序：先 names（exact 整字段），后 text（sub 子串，单趟、最长键优先）；纯 ASCII 字段只走 exact、不经 OpenCC。

## 词表生成（scripts/）

| 脚本 | 产物 | 说明 |
|---|---|---|
| `make_kivowiki_names.py` | `names.tsv` + `text.tsv` | 从 kivowiki 古书馆数据（缓存 `work/students.json`）自动生成，**每次完整重写，勿手工编辑**；`--refresh` 强制重新下载 |
| `make_name_template.py` | `names_custom.tsv` + `text_custom.tsv` | 自制词表模板：names 是恒等行（`聖園彌香<TAB>聖園彌香`），改右列即生效；未填写（左右相同）的行加载时自动跳过；text 是空模板全手写 |

自动生成规则：键 = 繁体名段（`聖園 彌香` → `彌香`）+ 全名连写（仅中日文）+ 皮肤名；text 表的皮肤名带括号（`(單車) → (骑行服)`），只命中 `白子(單車)` 这类复合串，不误伤正文裸词。值取民间简体名（繁→简流程直接输出简体；繁→繁流程需自己在模板里写繁体民译）。

## 黑名单（glossary/blacklist*.txt）

一行一个繁体键，可选第二列限定生效表：

```text
武裝          # names 与 text 都禁用
希望	text    # 仅 text 禁用（角色名照常生成，正文子串不替换）
```

`blacklist.txt` 客观共享（入库）；`blacklist.local.txt` 个人项（不入库，生成脚本同样读取，写在这里而不是删行——删了会被重新生成复活）。黑名单角色名段时，其派生全名一并禁用（如禁 `三森` 则 `水羽三森` 也不替换）。

## 调试（scripts/scan_fields.py）

字段级扫描：关键词在哪些表、以什么形态出现。字段分三类统计——kana（含假名，只计数）、cjk（中文字段）、ascii（纯拉丁，`--ascii` 开启才扫）。

```pwsh
# 关键词定位（多关键词、表名正则、样本条数）
uv run python scripts/scan_fields.py work/db/ExcelDB.db 瀬奈 Kei --limit 3
uv run python scripts/scan_fields.py work/db/ExcelDB.db 白子 --tables Etc

# 两库对比：验证替换效果（残留归零才算干净）
uv run python scripts/scan_fields.py output/ExcelDB.db 瀬奈 Kei --diff work/db/ExcelDB.db

# 未覆盖表清单：找还有哪些表该进 DEFAULT_TABLE_PATTERN
uv run python scripts/scan_fields.py work/db/ExcelDB.db --uncovered
```

常见排查路径：游戏里仍有旧文本 → `scan_fields.py <输出库> <关键词> --diff <输入库>` 看残留；两库都有 → 键写法不对（异体字 瀬/瀨、假名字段被跳过）或表不在 `--tables` 正则内，用 `--uncovered` 验证；只在输入库有且词表有该键 → dry-run 看 hits 是否为 0。

## 文本导出（scripts/export_texts.py）

把目标表的中文字段导出成可读 TSV，作翻译底稿 / 语料排查用。每表一个 `<表名>.tsv`（UTF-8 BOM），四列 `rowid / key / slot / text`，每个字段一行；正文里的 Tab 与换行转义成字面 `\t` / `\n` 保证一行一条。`rowid + slot` 是对应回数据库的锚点。

```pwsh
# 全量导出到 output/（默认表正则、默认跳过假名与纯拉丁字段）
uv run python scripts/export_texts.py work/db/ExcelDB.db

# 只导部分表；--kana / --ascii 分别追加日文死数据与纯拉丁字段
uv run python scripts/export_texts.py work/db/ExcelDB.db --tables Localize --out output/export
```

## glossary/ 文件一览

| 文件 | 性质 | 入库 | 用途 |
|---|---|---|---|
| `blacklist.txt` | 客观禁用项 | 是 | 通用词皮肤名、单字名、与普通词同形的角色名 |
| `terms.tsv` | 通用专名（sub） | 是 | 奇普托斯→基沃托斯 这类社区共识民译 |
| `blacklist.local.txt` | 个人禁用项 | 否 | 译名偏好排除（三森/柴大將 等） |
| `names.tsv` / `text.tsv` | 纯自动产物 | 否 | 每次生成脚本完整重写 |
| `names.local.tsv` / `text.local.tsv` | 手工修正 | 否 | 优先级最高的个人补充 |
| `names_custom.tsv` / `text_custom.tsv` | 自制词表 | 否 | 繁→繁民译用，恒等行模板 |

TSV 格式均为 `旧词<TAB>新词`，分隔符是 Tab 不是空格；`#` 开头为注释；允许 BOM（Excel 导出兼容）。

## 典型工作流

1. 更新词表：`uv run python scripts/make_kivowiki_names.py`（改了黑名单/数据源后重跑）
2. 预演检查：`uv run batr work/db/ExcelDB.db --dry-run`，确认无 `hits=0` 的新词条、无重复键告警
3. 打补丁：`uv run batr work/db/ExcelDB.db --out output/ExcelDB.db --verify`（CRC32 对齐 + integrity_check）
4. 用 `output/ExcelDB.db` 替换游戏文件
5. 抽查验证：`uv run python scripts/scan_fields.py output/ExcelDB.db <关键词> --diff work/db/ExcelDB.db`
