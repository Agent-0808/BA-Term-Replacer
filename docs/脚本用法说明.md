# 脚本用法说明

日常操作手册。工具原理见 [HOW\_IT\_WORKS.md](HOW_IT_WORKS.md)。

所有命令在仓库根目录执行，命令一律写作 `uv run batr <子命令> ...`。

## 子命令总览（src/batr/cli.py）

| 子命令        | 作用                                                             |
| ---------- | -------------------------------------------------------------- |
| `patch`    | 繁中 ExcelDB.db 做字段级文本补丁，输出 CRC32 与输入一致的库；`--install` 可覆盖安装到游戏目录 |
| `scan`     | 字段级扫描（调试）：关键词定位 / 两库对比 / 未覆盖表清单                                |
| `export`   | 把目标表的中文字段导出成可读 TSV                                             |
| `glossary` | 词表编译：数据源 + 手写词表 + 黑名单 → `glossary/compiled.tsv`（`--template` 生成恒等行模板） |
| `paths`    | 显示检测到的游戏安装路径与 ExcelDB.db 路径                                    |

除 `glossary` 外的子命令都接受可选的 `--db` 参数：**省略时自动从注册表定位游戏客户端内的库**（`--region auto|global|japan` 控制区服，auto = global 优先、japan 兜底），需要时显式给出即可。`uv run batr paths` 可排查自动定位结果。

## patch

```pwsh
# 繁→简（默认流程）：tw2sp + 编译词表；--db 省略时自动定位游戏客户端，也可显式给出
uv run batr patch --db work/db/ExcelDB.db --out output/ExcelDB.db --verify

# 繁→繁民译：--profile t2t 自动绑定 convert=none，不再要记三个参数
uv run batr patch --profile t2t

# 预演：只统计会改什么、逐条打印词表命中数（hits），不写任何文件
uv run batr patch --dry-run

# 补丁 → 覆盖安装到游戏目录一步到位（覆盖前自动备份 .bak，交互确认 y/N）
uv run batr patch --install
```

常用参数：

| 参数                           | 作用                                                              |
| ---------------------------- | --------------------------------------------------------------- |
| `--db`                           | 输入 ExcelDB.db（不会被修改）；省略则自动定位游戏安装路径                              |
| `--out`                      | 输出库（另存，CRC32 与输入一致；默认 `output/<输入文件名>`，--dry-run 时可省略）          |
| `--profile {t2s,t2t}`       | 词表流程：t2s 繁→简（默认）/ t2t 繁→繁（自动绑定 `--convert none`）                 |
| `--convert {tw2sp,t2s,none}` | tw2sp 含台湾用词转换；t2s 只转字形；none 只做词表替换（显式给出则覆盖 profile 缺省）           |
| `--glossary 路径`             | 编译词表产物（默认 `glossary/compiled.tsv`，`batr glossary` 生成）            |
| `--dry-run`                  | 预演，排查词条用（重点看 `hits=0` = 键拼错或过期）                                 |
| `--verify`                   | 完成后对输出库跑 `PRAGMA integrity_check`                               |
| `--no-ascii-exact`           | 关闭纯 ASCII 字段的 exact 匹配（默认开启，覆盖 "Kei" 这类纯拉丁角色名）                  |
| `--tables 正则`                | 限定处理的表名，默认含 `Localize/Dialog/Scenario/.../Messanger/SNSProfile` |
| `--convert-kana`             | 不跳过含假名字段（默认跳过：日文列是 GL 死数据）                                      |
| `--region`                   | 自动定位游戏路径用的区服（auto = global 优先，japan 兜底）                         |
| `--install`                  | 补丁成功后把输出库覆盖到游戏目录（与 --dry-run 互斥）                                |
| `--yes`                      | 覆盖安装跳过交互确认（非交互环境必须显式给出）                                         |

覆盖安装行为：确认前打印源/目标的完整路径、大小与修改时间；覆盖前自动把游戏原库备份为 `ExcelDB.db.bak`（回滚手段，直接改回文件名即可）；目标被占用（游戏未关）时报错提示。

词表只读编译产物 `glossary/compiled.tsv`（合并顺序与黑名单过滤已在编译期完成）。匹配顺序：先 exact（整字段相等），后 sub（子串，单趟、最长键优先）；纯 ASCII 字段只走 exact、不经 OpenCC。

## glossary（词表编译）

```pwsh
uv run batr glossary              # 编译：auto 条目 + 手写词表 + 黑名单 → glossary/compiled.tsv
uv run batr glossary --profile t2t  # 繁→繁流程：auto 不编入，只编手写词表
uv run batr glossary --template   # 往 glossary/local/ 补恒等行脚手架（繁→繁民译用），不编译
```

- 数据源：KivoWiki 民译（缓存 `work/BACII_students.json` 与 `work/BACII_skin_map.json`，`--refresh` 强制重下）。auto 条目不落盘，每次编译重新生成，仅 t2s profile 编入。
- 手写词表：`glossary/shared/*.tsv`（客观共识，入库可 PR）与 `glossary/local/*.tsv`（个人偏好，不入库）全部扫描；匹配方式由各文件头 `# mode: exact|sub` 声明（缺省 sub）。加载顺序 auto → shared → local，**后加载者优先**（个人覆盖共享、手写覆盖自动），同键覆盖时编译日志报告。
- `local/` 缺文件自动从 `templates/` 复制（已存在的不动，绝不覆盖用户内容；删除后重跑得到新空模板）。
- 产物 `compiled.tsv`（gitignore）注释头记录 profile、生成时间与来源统计；patch 的唯一输入。

`--template` 模板模式：往 `local/name.tsv` 追加名段 / 全名连写 / 皮肤名恒等行，往 `local/text.tsv` 追加皮肤括号恒等行（`(單車)<TAB>(單車)`）；已有内容逐行保留、只补新增键（shared/local 中同 mode 已有的键不补），未填写的恒等行若已不在生成集合里则删除。右列与左列相同的行 = 未填写，编译加载时自动跳过。

自动生成规则：键 = kivo 繁体字段的名段（`given_name_tw`）+ 全名连写（`family_name_tw + given_name_tw`，仅中日文）+ 皮肤名；皮肤名带括号的键（`(單車) → (骑行服)`）只命中 `白子(單車)` 这类复合串，不误伤正文裸词。值取 kivo 无后缀简中民译字段（繁→简流程直接输出简体；繁→繁流程在 `local/` 恒等行模板里写繁体民译）。

## 黑名单（glossary/shared/blacklist.txt + glossary/local/blacklist.txt）

一行一个繁体键，可选第二列限定匹配方式（编译期对自动与手写**一切来源**过滤）：

```text
武裝          # exact 与 sub 都禁用
希望	sub    # 仅禁子串匹配（角色名整字段照常替换，正文子串不替换）
```

`shared/blacklist.txt` 客观共享（入库）；`local/blacklist.txt` 个人项（不入库）。黑名单角色名段时，其派生全名一并禁用（如禁 `鹿江` 则 `板垣鹿江` 也不替换）。

## scan（调试）

字段级扫描：关键词在哪些表、以什么形态出现。

字段分三类统计——kana（含假名，只计数）、cjk（中文字段）、ascii（纯拉丁，`--ascii` 开启才扫）。

```pwsh
# 关键词定位（多关键词、表名正则、样本条数；db 省略时自动定位游戏库）
uv run batr scan 瀬奈 Kei --limit 3
uv run batr scan 白子 --tables Etc

# 两库对比：验证替换效果（残留归零才算干净）
uv run batr scan 瀬奈 Kei --diff work/db/ExcelDB.db

# 未覆盖表清单：找还有哪些表该进 DEFAULT_TABLE_PATTERN
uv run batr scan --uncovered
```

常见排查路径：
- 游戏里仍有旧文本 → `scan <关键词> --diff work/db/ExcelDB.db` 看残留：
    - 两库都有 → 键写法不对（异体字 瀬/瀨、假名字段被跳过）或表不在 `--tables` 正则内，用 `--uncovered` 验证；
    - 只在输入库有且词表有该键 → dry-run 看 hits 是否为 0。

## export（文本导出）

把目标表的中文字段导出成可读 TSV，作翻译底稿 / 语料排查用。每表一个 `<表名>.tsv`（UTF-8 BOM），四列 `rowid / key / slot / text`，每个字段一行；正文里的 Tab 与换行转义成字面 `\t` / `\n` 保证一行一条。`rowid + slot` 是对应回数据库的锚点。

```pwsh
# 全量导出到 output/tables/（默认表正则、默认跳过假名与纯拉丁字段）
uv run batr export

# 只导部分表；--kana / --ascii 分别追加日文死数据与纯拉丁字段
uv run batr export --tables Localize --out output/export
```

## glossary/ 文件一览

| 文件                              | 性质           | 入库 | 用途                              |
| -------------------------------- | ------------ | -- | ------------------------------- |
| `shared/name.tsv`                | 共享角色名（exact） | 是  | 含 KivoWiki 键差错的显式修正，可 PR        |
| `shared/text.tsv`                | 共享正文替换（sub）  | 是  | 奇普托斯→基沃托斯 这类社区共识民译，可 PR         |
| `shared/blacklist.txt`           | 客观禁用项        | 是  | 通用词皮肤名、单字名、与普通词同形的角色名           |
| `templates/name.tsv` 等           | 空模板          | 是  | 格式的事实来源，`local/` 缺文件时自动复制       |
| `local/name.tsv` / `text.tsv`    | 手工修正         | 否  | 个人偏好，后加载优先于 shared              |
| `local/blacklist.txt`            | 个人禁用项        | 否  | 译名偏好排除（三森/柴大將 等）                |
| `compiled.tsv`                   | 编译产物         | 否  | `batr glossary` 每次重写，patch 唯一输入 |

TSV 格式均为 `旧词<TAB>新词`，分隔符是 Tab 不是空格；`#` 开头为注释；匹配方式由文件头 `# mode: exact|sub` 声明（缺省 sub）。文件名不承载语义，可按内容任意拆分文件（如 `shared/orgs.tsv`），编译器照常扫描。

## 典型工作流

1. 更新词表：`uv run batr glossary`（改了手写词表/黑名单后重跑；繁→繁用 `--profile t2t`）
2. 预演检查：`uv run batr patch --dry-run`，确认无 `hits=0` 的新词条、无重复键告警
3. 打补丁：`uv run batr patch --out output/ExcelDB.db --verify`（CRC32 对齐 + integrity\_check）
4. 抽查验证：`uv run batr scan <关键词> --diff work/db/ExcelDB.db`
5. 安装：`uv run batr patch --install`（或第 3 步直接合并为 `uv run batr patch --install --verify`）
